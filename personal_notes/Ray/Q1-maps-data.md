# Q1 maps: September 2026 Airbnb listings and Council Tax dwellings

Open [q1_basic_maps.ipynb](q1_basic_maps.ipynb) from this folder in the FSDS Python environment. Keep the adjacent `data/` folder in place and run the cells from top to bottom. The ranked table and Map 2 share the same calculation: distinct entire-home Airbnb listings per 100 dwellings on the Council Tax valuation list.
